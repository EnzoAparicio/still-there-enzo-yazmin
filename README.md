# Still There (Siguen Ahí)

**Play the demo:** https://enzoaparicio.github.io/still-there-enzo-yazmin/

Prototype for the **NASA Space Apps Challenge 2026** · Challenge: *Abandoned but not Forgotten: Storytelling about NASA's Discarded Equipment on the Moon and Mars* · **Team EnYi** (Uruguay).

Still There is a web game where kids aged 9–12 become space explorers and find the machines NASA left behind on the Moon and Mars.

## How to play
1. Choose a world: **Moon** or **Mars**.
2. Explore the real NASA map. Each pin marks a machine at its real location.
3. Tap a pin and read the machine's story, told in first person, with a real NASA photo.
4. Answer the challenge question.
5. Switch between **English and Spanish** at any time (🌐 button).

No installation, login or registration needed: it runs in any modern browser, on a computer, tablet or phone.

## NASA data used
- Maps: NASA Solar System Treks (Moon: LRO WAC global mosaic; Mars: Viking MDIM 2.1 color mosaic)
- Photos: NASA Image and Video Library (AS11-40-5942, AS15-86-11603, PIA17759, PIA24648)
- Facts: NSSDCA and NASA Science mission pages
